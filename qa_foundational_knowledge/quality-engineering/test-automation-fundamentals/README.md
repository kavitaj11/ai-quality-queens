# Test automation fundamentals · Training guide

Start with **Test engineering** to learn how to select risks, design checks and decide what evidence a release needs. Use **Tools and technologies** to practice those decisions in a browser, a behavior specification and a database. The AI lessons extend the same reasoning to interpreting results and controlling a test run. Use the interview lessons to explain decisions from your own experience.
