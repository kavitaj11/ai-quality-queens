# Even Odd Partition

Move misplaced values across a left and right boundary.

## Work through it

Try [3,2,1,4]: check that even values precede odd values, without assuming either group is sorted.

**Cost in this implementation:** O(n).

Read the [Java implementation](EvenOddPartition.java). Before stepping through it, write down the state you expect after the first operation. Compare it with the next state in the code and explain what fact remains true.
