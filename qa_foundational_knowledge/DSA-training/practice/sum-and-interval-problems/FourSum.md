# Four Sum

Reduce a four-value target to smaller sum problems and finish with pairs.

## Work through it

Trace [0,0,0,0,0] for target zero: multiple index choices should not duplicate the value tuple.

**Cost in this implementation:** O(n^3).

Read the [Java implementation](FourSum.java). Before stepping through it, write down the state you expect after the first operation. Compare it with the next state in the code and explain what fact remains true.
