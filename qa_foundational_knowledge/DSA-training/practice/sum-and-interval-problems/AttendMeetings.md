# Attend Meetings

Check whether any pair of meetings overlaps.

## Work through it

Compare [1,3) with [3,4) and then [2,4): touching endpoints are allowed, shared time is not.

**Cost in this implementation:** O(n^2).

Read the [Java implementation](AttendMeetings.java). Before stepping through it, write down the state you expect after the first operation. Compare it with the next state in the code and explain what fact remains true.
