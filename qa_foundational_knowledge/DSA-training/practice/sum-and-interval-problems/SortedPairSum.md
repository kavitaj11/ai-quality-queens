# Sorted Pair Sum

On a sorted list, adjust opposite ends according to their sum.

## Work through it

With [1,3,5,8] and target 8, explain why discarding 8 first cannot lose a solution.

**Cost in this implementation:** O(n).

Read the [Java implementation](SortedPairSum.java). Before stepping through it, write down the state you expect after the first operation. Compare it with the next state in the code and explain what fact remains true.
