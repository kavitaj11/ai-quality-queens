# Three Sum

Fix one value in a sorted list and search for a complementary pair.

## Work through it

Try [-1,0,1,1]; distinguish unique value triples from distinct index triples.

**Cost in this implementation:** O(n^2 + n * log(n)).

Read the [Java implementation](ThreeSum.java). Before stepping through it, write down the state you expect after the first operation. Compare it with the next state in the code and explain what fact remains true.
