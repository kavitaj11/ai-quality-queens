# 07 · Playwright

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 9–12

## What to study

Separate browser, context and page lifetimes. Use semantic locators, web-first assertions, fixtures and controlled network responses. Read traces and distribute tests across projects and shards.

## Practice assignment

Run a checkout test in isolated contexts and inspect a trace from a deliberately incorrect expected result.
