# 11 · Non-Functional Testing

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 21–22

## What to study

Plan performance, accessibility, compatibility, usability and recovery checks. Define a workload and interpret response-time distributions. Include localization and security requirements in acceptance criteria.

## Practice assignment

Write a workload profile and a percentile latency target. Pair it with a keyboard-only check of the same journey.
