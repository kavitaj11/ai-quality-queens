# 05 · Networking

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 4

## What to study

Follow DNS resolution, TCP, TLS and an HTTP exchange. Read headers, cookies, cache behavior and browser CORS messages. Compare polling with WebSockets and server-sent events.

## Practice assignment

Use a sanitized network trace to locate a failed request and identify the earliest observable failure.
