# 06 · Selenium

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 4–8

## What to study

Follow a WebDriver command from the test to the browser. Practice locators, explicit waits, frames, windows and alerts. Use page objects, listeners and Grid to organize and diagnose parallel runs.

## Practice assignment

Replace a fixed sleep with a condition that represents readiness. Show that the assertion still catches a wrong final value.
