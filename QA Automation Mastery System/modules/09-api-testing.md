# 09 · API Testing

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 16–18

## What to study

Validate status, headers, response shape and business outcomes using requests, REST Assured or Playwright. Explore request chaining, schema validation, Pact contracts and resilience.

## Practice assignment

Validate an order response against its schema, then show a schema-valid response that violates a business rule.
