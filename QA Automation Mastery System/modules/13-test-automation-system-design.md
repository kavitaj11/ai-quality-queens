# 13 · Test Automation System Design

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 22–23

## What to study

Compare Java, Python, TypeScript and .NET framework designs. Separate business language, test fixtures, clients and reporting. Plan how multiple stacks can exchange results.

## Practice assignment

Sketch a framework for two teams using different languages. Define a shared result format and identify who owns each failure.
