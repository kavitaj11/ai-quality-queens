# 00 · SDLC & Test Engineering

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 5–6

## What to study

Trace a requirement through the SDLC and STLC. Distinguish strategy from a release plan, and connect exploratory testing, automation and model evaluation to release evidence.

## Practice assignment

Write a checkout release plan naming the risk, owner, test level and exit criterion for each check.
