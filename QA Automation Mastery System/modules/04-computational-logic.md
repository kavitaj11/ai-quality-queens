# 04 · Computational Logic

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 3–4

## What to study

Use sets, maps, search and complexity analysis to reason about test utilities. Apply pairwise coverage, invariants and probability to test design. Connect confusion matrices and vector similarity to evaluation.

## Practice assignment

For a defect classifier, construct a confusion matrix and calculate precision and recall. Explain which missed defects matter most.
