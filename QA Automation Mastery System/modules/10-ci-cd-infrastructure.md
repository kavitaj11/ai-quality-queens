# 10 · CI/CD & Infrastructure

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 19–21

## What to study

Run suites in GitHub Actions or Jenkins with disposable Docker environments. Examine cloud browser coverage, suite selection, flaky-test triage, observability and progressive delivery.

## Practice assignment

Design a fast PR gate and a broader scheduled suite. Specify the artifacts a reviewer needs when either fails.
