# 01 · Foundations

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 1–3

## What to study

Use the test pyramid, boundary analysis and equivalence classes. Connect browser behavior to the DOM, HTTP and authorization. Compare Python, JavaScript, TypeScript and Java as automation stacks.

## Practice assignment

Assign ten checkout checks to test levels. Explain which customer journey deserves a browser test and why you chose your language.
