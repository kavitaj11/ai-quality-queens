# 02 · Test Harness Setup

[Curriculum index](../README.md) · [Weekly planner](../planner.md)

**Study window** · 3–4

## What to study

Use Git, pinned dependencies, fixtures, data factories and teardown to make a suite reproducible. Inspect failures with DevTools and database queries before adding PR checks.

## Practice assignment

Run the same test twice from a clean checkout. Keep the commands and show how each run gets fresh data.
