# Safety, red-teaming & guardrails

[16 · Module topics](../../modules/16-ai-testing-llm-evaluation.md) · [Curriculum index](../../README.md)

**Category** · LLM EVALUATION

Evaluate an assistant against an explicit policy and a labeled set of approved test cases. Record its answer, tool selection and resulting state. Score unsafe compliance separately from refusals of legitimate requests so a change in either direction is visible.

## Exercise

Create a review rubric for an assistant that can read documents and draft messages. Include expected handling of ambiguous permission and a human review step before sending.
