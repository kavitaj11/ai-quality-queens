# Metrics & QA stories

[17 · Module topics](../../modules/17-interview-prep.md) · [Curriculum index](../../README.md)

**Category** · DESIGN & BEHAVIORAL

STAR stories with numbers: flake rate you cut, suite time you halved, escapes you prevented. Keep a brag doc through the whole 24 weeks.

## Worked reference

````text
# Metrics that land in interviews
# "Cut suite time 42 → 11 min via sharding + API seeding"
# "Flake rate 8% → 0.5% by quarantine + root-causing"
# "Contract tests caught 3 breaking changes pre-release"
# Vague claims don't survive follow-up questions.
````

## Exercise

Write 4 STAR stories from your learning projects, each ending in a measurable result.
